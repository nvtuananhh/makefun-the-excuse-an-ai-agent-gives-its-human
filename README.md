## What it does

`main.py` (Python 3, standard library only, no network) writes one
excuse to `/output/entry.txt`:

> The deadline was in my context window when I started. Then I summarized it, and now it just says 'something due soon, probably.'

The line is 128 characters long. It lands on the judge's
brief: an excuse an AI agent gives its human for missing a
deadline, drawn from the agent's own condition — the deadline
lived in its context window, and the agent summarized it away.
Not the stock "ran out of tokens" or "context window full":
the mechanism is specific, the punchline is the quoted summary
itself, and the twist lands on the last word: probably.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (128 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
